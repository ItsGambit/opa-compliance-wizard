Checking this package

Run the checking program on the zip file, with Python 3, without unpacking it: python3 -I verify_evidence_package.py <package file name>.zip. Read README-FOR-AUDITORS.txt for the steps.

sha256 of the checking program shipped with this build@@VERIFIER_SHA256@@

This value and the copy of the program inside the package came from the same place as the package and prove nothing about themselves. The authoritative sha256 is in the signed release and its release notes and on the project's signing-key page: compare the sha256 of the program you run with that value. The check detects accidental or partial change and compares the exported events with the archive's hash chain as it stood when the package was built. Hashes are unkeyed and the package is not signed; it does not show who produced the events. The server's own build log is the independent record: compare the zip's sha256 and the chain head with it.

This package holds personal data (names, email addresses, IP addresses and activity) and is not encrypted.
